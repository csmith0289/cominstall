# 08: Manage Users

**What to build:** Admins change Roles and deactivate or reactivate Users.

**Blocked by:** 02

**Status:** blocked

- [ ] Admin → Users lists Users (name, email, Role, active or not, last sign-in) and pending Invitations.
- [ ] An Admin can change a User's Role and deactivate or reactivate them; deactivating ends their sessions at once.
- [ ] An Admin can't deactivate themselves or remove the last active Admin.
- [ ] Each change is written to the Audit Log.
- [ ] A deactivated Engineer's Job Cards stay, and can be reassigned.
